# Artwork

`mark.svg` is the original Amy OS cat, vectorized from a concept created
with the built-in imagegen tool. `./branding/render.sh` rebuilds every PNG and
the Debian boot-menu SVG; it needs librsvg and Python 3.

Concept brief: “An original standing cat in side profile, facing right, with
a raised tail, natural proportions and a smooth, solid silhouette. No lettering
or interior detail.”

The artwork is black and white only: no wordmark, colored tile, outline or
decorative line. Amy OS runs Breeze Dark, so the system uses a plain white cat
on dark backgrounds. The README also has a black cat for GitHub's light theme.

The same geometry supplies every variant.
