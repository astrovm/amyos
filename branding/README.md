# Artwork

`mark.svg` is the original Amy OS cat, drawn as a vector from a concept created
with the built-in imagegen tool. `./branding/render.sh` rebuilds every PNG and
the Debian boot-menu SVG; it needs librsvg and Python 3.

Concept brief: “An original walking cat in side profile, facing right, with
a raised tail, natural proportions and a smooth, solid silhouette. The simple
style of the old logo, with a fresh drawing. No lettering or interior detail.”

The same geometry supplies the black and white README marks, desktop and
installer icons, welcome graphic and boot splash. The old downloaded cat is
replaced throughout.
